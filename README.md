# Kaggle Dataset Collection

This repository brings together datasets published by the **mjwad17 Kaggle profile**. Each dataset folder contains its data files and a README with details about the dataset and possible uses.

**Datasets in this repository: 4**

| Dataset | Description |
| --- | --- |
| [Basketball Injury & Biomechanical Dataset](./Basketball_Injury_Biomechanical/) | Basketball player injuries, biomechanical measurements, and rehabilitation outcomes. |
| [English Language Learning & Proficiency Benchmarks](./English_Language_Learning_%26_Proficiency_Benchmarks/) | Learner profiles, platform engagement, and English proficiency assessments. |
| [NVIDIA Corporation Common Stock](./NVIDIA_Corporation_Common_Stock/) | Historical NVIDIA (NVDA) trading data, including daily prices and trading volume. |
| [Volleyball Smart Sensors & Biometrics](./Volleyball_Smart_Sensors-%26-Biometrics/) | Volleyball movement, wearable sensor telemetry, biometrics, and performance feedback. |

The collection covers sports science, education, and financial time-series data for exploration, analysis, and machine-learning projects.

For the datasets published on Kaggle, visit the [mjwad17 Kaggle datasets page](https://www.kaggle.com/datasets/mjwad17).
