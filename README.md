# Kaggle Dataset Collection

This repository brings together datasets published under the **mjwad17 Kaggle profile**. Each folder contains source data files and a README with context, schema notes, and possible analytical use cases.

## Repository overview

The collection currently includes 10 dataset folders covering sports analytics, education, finance, energy, social sentiment, behavioral data, and public infrastructure.

| Dataset | Folder | Focus area |
| --- | --- | --- |
| [Basketball Injury & Biomechanical Dataset](./Basketball_Injury_Biomechanical/) | `Basketball_Injury_Biomechanical` | Sports injury risk, biomechanics, and rehabilitation outcomes |
| [English Language Learning & Proficiency Benchmarks](./English_Language_Learning_%26_Proficiency_Benchmarks/) | `English_Language_Learning_&_Proficiency_Benchmarks` | Education analytics and language-learning performance |
| [Financial Market Trends (2021-2023)](./Financial%20Market%20Trends%20(2021-2023)/) | `Financial Market Trends (2021-2023)` | Macro-finance, volatility, and time-series market analysis |
| [NVIDIA Corporation Common Stock](./NVIDIA_Corporation_Common_Stock/) | `NVIDIA_Corporation_Common_Stock` | Historical daily stock data for NVDA |
| [Pakistan Petrol Prices (2013-2026)](./Pakistan_Petrol_price_2013-2026/) | `Pakistan_Petrol_price_2013-2026` | Fuel-price analysis across major Pakistani cities |
| [Punjab Pakistan Water & Sanitation Infrastructure](./Punjab_Pakistan_Water_and_Sanitation_Infrastructure/) | `Punjab_Pakistan_Water_and_Sanitation_Infrastructure` | Public utility and infrastructure reporting |
| [Reddit Stock Sentiment: Tech & Semiconductor Data](./Reddit_Stock_Sentiment_Tech_and_Semiconductor_Data/) | `Reddit_Stock_Sentiment_Tech_and_Semiconductor_Data` | Financial NLP, sentiment analytics, and semiconductors |
| [Smartphone Addiction & Screen Time Behavior](./Smartphone_Addiction_&_Screen_Time_Behavior/) | `Smartphone_Addiction_&_Screen_Time_Behavior` | Behavioral data and digital dependency modeling |

| [Water & Sanitation Infrastructure](./Water_and_Sanitation_Infrastructure/) | `Water_and_Sanitation_Infrastructure` | Public-sector water and sanitation infrastructure records |

## Project themes

This repository spans a diverse set of analysis workflows:

- Sports science and injury prediction
- Educational assessment and learner modeling
- Financial market forecasting and event analysis
- Sentiment-driven NLP in stock discussions
- Behavioral and lifestyle classification
- Public infrastructure and regional development analysis

## Notes

- Some dataset folders contain fully documented project READMEs; others are data-focused folders with CSV assets and supporting images.
- Use the per-folder README for schema details, methodology notes, and recommended modeling tasks.

For the datasets published on Kaggle, visit the [mjwad17 Kaggle datasets page](https://www.kaggle.com/datasets/mjwad17).
